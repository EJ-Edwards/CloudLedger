# CloudLedger

CloudLedger is a server inventory CLI tool for homelabbing hobbyist. It connects to an IP address via SSH and saves the servers OS and disk information all of it to a local file in json.


## Setup

1. Make sure python is installed then install the packages CloudLedger uses which is rich and paramiko.
2. How you install the dependencies is 
```sh
python -m pip install -r requirements.txt
```
3. Then you type into the terminal 
``` sh
cd src
```
then to run the project you do
``` sh
python3 main.py
```
4. Final rule have fun with this project if you have any ways this can be improved open an issue and give feedback.
